Equalturn registry staging

This is a non-production TUF repository used for client interoperability tests.

Its metadata and registry target are public test data. They do not establish production trust, and Equalturn does not use this registry for workstation enforcement.

This fixed branch is deployed through the staging-only GitHub Pages workflow. Only this branch's static files are published; clients verify TUF metadata against an independently pinned root.
